# 论文与学术文本

## 主线：把已成立的贡献讲清楚

先问本段在解释什么问题、哪项证据支持它。论文围绕真正成立的价值组织：能力、机制、问题设定、效率、成本、适用性或可检验的权衡，不是平均罗列所有做过的事。

- 摘要/引言尽早交代问题、现有缺口、具体思路、最有分量的已给结果及其含义。不要用时代背景和“近年来广受关注”占据开头。
- 方法说明挑战如何对应设计，实验说明结果支持哪个主张。没有必要按“先试A、再试B、最后选C”的研发顺序展开。
- 讨论不领先的指标时如实解释目标、条件与权衡，不把一个局部结果上升成整体失败。不得因此隐藏必要比较、更换统计口径或删除实质反例。
- 结论强化已经建立的发现与适用意义；不要突然增加未论证的新贡献、新的普遍性承诺或一段机械自我否定。已知重要局限依然应在恰当位置保留。
- 用户只授权润色时，不替作者重新定义研究问题、改实验排名或重排整篇论文。可以单独提出重构建议。

## 主张与证据逐一对应

| 原稿情况 | 可做 | 不可做 |
| --- | --- | --- |
| 有结果但表述笼统 | 指向已有表、图、数值和条件 | 为显得具体补一组新数字 |
| 动词强于证据 | 在不改变结果的前提下收窄表述；必要时说明 | 把经验观察写成定理或因果证明 |
| 缺少支撑 | 标明需要什么证据，或删除无信息评价 | 编造引用、显著性检验或实验 |
| 局部表现不佳 | 准确报告条件、差异和合理权衡 | 通过省略关键结果制造全面领先 |
| “首次/最优/显著” | 检查是否已有范围说明、比较或检验 | 用“据我们所知”替代实际核验 |

形式证明可以用“prove”；经验结果可以用“show”或有依据的“demonstrate”。不要机械禁用动词，区分理论结论、实证观察和推测。若没有统计检验，不把“更高”润色成“statistically significant”。

引用不能只剩一串编号：可在已有事实范围内说明关键工作与当前问题的关系，但不自行推断被引论文的结论。不因“减少citation dumping”而擅自删引用键。

## 语言与声音

- 保留有效限定：“on the evaluated datasets”“suggests”“may indicate”常是精确表达，不是软弱。删除的是重复、无对象、无理由的模糊。
- 学术“we”、必要被动语态、正式定义、技术术语、数学符号和领域习惯都可以自然存在。
- 拆分承载多个逻辑层级的长句，不设所有句子统一字数上限。拆句后保留条件、否定、比较对象和指代关系。
- 缩短“值得注意的是”“it should be emphasized that”等导语，让后面的事实直接说话。
- 不给全文硬塞口语、情绪、第一人称经历或“像真人一样的小错误”。
- 对破折号、分号、三项列表和贡献列表按功能判断；用户/期刊明确限制时才按限制执行。不要把合法标点改坏，尤其不要动数值范围、负号或LaTeX命令。

## Rebuttal / 回复审稿意见

按“问题 → 直接回答 → 已有证据或真实改动 → 精确位置”组织。承认确实存在的问题，不附和错误前提，也不攻击审稿人。区分“已完成”“计划完成”“目前无法确认”；没有运行实验就不能写“已补充实验”。只有用户授权的可行修改才可作承诺。遵守用户给定字数、匿名要求和文件边界。

## 保真检查

修订后检查：贡献是否仍是同一个贡献；每一处数量、单位、条件、公式、表图号、引用键是否保持；没有增删因果性、基线、数据集范围、置信度或研究结论。原稿存在矛盾时单独标出，不能用语言润色掩盖。
